# How to Use Command History to Recall and Re-execute Commands

This guide shows you how to search, select, edit, and re-execute previous commands using `history`, `Ctrl-R`, and history expansion operators, and how to remove sensitive commands from history.

---

## Before You Begin

Ensure you have:

- An active Bash shell session with a populated history list (at least several prior commands issued)
- Write access to `~/.bash_history` (normal for any regular user or root in their own home directory)

---

## Steps

### 1. Display the history list with line numbers

Print the full history list to identify commands by number.

```bash
history
```

To limit output to the most recent entries:

```bash
history 20
```

---

### 2. Re-execute a command by history number

Run any command from the list using its history number.

```bash
!42
```

Replace `42` with the number shown in the history list.

---

### 3. Re-execute the last command with `!!`

Repeat the immediately preceding command.

```bash
!!
```

To repeat the last command with elevated privileges:

```bash
sudo !!
```

---

### 4. Re-execute the most recent command matching a string prefix

Run the last command that began with a given string.

```bash
!ls
```

Replace `ls` with the prefix that matches the command you want.

> **Note:** This executes immediately without confirmation. Verify the intended command in the history list first if the action is destructive.

---

### 5. Search history interactively with Ctrl-R

Press `Ctrl-R` at the prompt and type a search string to find the most recent matching command.

```
(reverse-i-search)`cat': cat /etc/hostname
```

- Press `Ctrl-R` again to cycle to the next older match.
- Press `Enter` to execute the displayed command.
- Press `Ctrl-G` to cancel the search without executing.

---

### 6. Recall and edit a command before executing

Use the Up arrow key to navigate to the command you want, then edit it on the command line before pressing Enter.

To move within the recalled line:

| Key | Action |
|---|---|
| `Ctrl-A` | Move cursor to beginning of line |
| `Ctrl-E` | Move cursor to end of line |
| `Ctrl-U` | Delete from cursor to beginning of line |
| `Alt-B` / `Alt-F` | Move backward / forward one word |

---

### 7. Substitute a string in the previous command with `^`

Correct a typo or change one token in the last command without retyping the whole line.

```bash
^old^new
```

Example — if you just ran `cat /etc/hostnam`, correct it with:

```bash
^hostnam^hostname
```

---

### 8. Delete a specific entry from history

Remove a single history entry by its line number to prevent sensitive commands from persisting.

```bash
history -d 42
```

Replace `42` with the line number of the command to remove.

To delete a range of entries, repeat with a loop or use consecutive deletions. After deletion, line numbers of subsequent entries shift — recheck with `history` before each deletion.

---

### 9. Clear the entire in-memory history list

Remove all history entries from the current session's memory.

```bash
history -c
```

---

### 10. Prevent a command from being saved to history

Prefix the command with one or more spaces. Bash omits space-prefixed commands from history when `HISTCONTROL` includes `ignorespace`.

```bash
 echo "my-secret-token"
```

To confirm this setting is active:

```bash
echo $HISTCONTROL
```

Expected value includes `ignorespace` or `ignoreboth`.

---

### 11. Write the current session history to disk immediately

Force the in-memory history to be written to `~/.bash_history` without waiting for the session to close.

```bash
history -w
```

---

## Verification

Confirm history operations are working correctly:

```bash
history | tail -10
```

The last 10 entries reflect recent commands in the correct order with sequential numbers.

To confirm a deleted entry is gone, search for it by number — the surrounding entries will have renumbered.

To confirm `~/.bash_history` reflects the current session:

```bash
tail -10 ~/.bash_history
```

Output matches the most recently written commands.

---

## Troubleshooting

| Problem | Cause | Solution |
|---|---|---|
| Space-prefixed commands still appear in history | `HISTCONTROL` does not include `ignorespace` | Run `export HISTCONTROL=ignoreboth` or add it to `~/.bashrc` |
| `history -d` removes the wrong entry | Line numbers shift after each deletion | Run `history` again after each deletion to get current numbers before the next `history -d` |
| `!string` executes the wrong command | Multiple commands share the same prefix; the most recent match is not the intended one | Use `!number` from the explicit history list instead, or use `Ctrl-R` to confirm the match visually |
| `~/.bash_history` does not update after `history -c` | `-c` clears in-memory history only; a subsequent session write overwrites the file with the now-empty list only after `history -w` or session close | Run `history -c && history -w` together to clear both memory and file |
| `Ctrl-R` finds no match | The command is not in the in-memory history list, or was deleted | Use `grep` against `~/.bash_history` directly: `grep pattern ~/.bash_history` |

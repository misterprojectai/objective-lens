# How to Get Help for Any Command at the Shell Prompt

This guide shows you how to locate usage information and option syntax for any command using the built-in help tools available at every RHEL shell prompt.

---

## Before You Begin

Ensure you have:

- An active Bash shell prompt on an RHEL system
- The name of the command you want to investigate (or a topic to search)

---

## Steps

### 1. Display a Command's Built-in Usage Summary

Run the command with `--help` to display a compact usage summary and available options.

```bash
ls --help
```

> **Note:** A small number of commands use `-h` instead of `--help`. If `--help` produces an error, try `-h`.

---

### 2. Open the Full Manual Page for a Command

Open the `man` page for complete documentation, including all options, argument syntax, and examples.

```bash
man ls
```

Navigate the manual page with these keys:

| Key | Action |
|---|---|
| `Space` or `f` | Scroll forward one page |
| `b` | Scroll back one page |
| `/pattern` | Search forward for text |
| `n` | Jump to next search match |
| `q` | Quit and return to the shell |

---

### 3. Read the Synopsis Section of a Man Page

Open any man page and locate the SYNOPSIS section immediately below the NAME section. Read it using this key:

- **Bold** text — type exactly as shown
- *Underlined* or *italic* text — replace with your own value
- `[item]` — optional; omit if not needed
- `item...` — repeatable; provide one or more

For example, the synopsis for `ls`:

```
ls [OPTION]... [FILE]...
```

This means: `ls` accepts zero or more options and zero or more file arguments, all optional.

---

### 4. Get a One-Line Description of a Command with whatis

Look up a brief description of any command without opening a full man page.

```bash
whatis ls
```

Expected output:

```
ls (1)               - list directory contents
```

Use `whatis` when you know a command name but want to confirm what it does before investigating further.

---

### 5. Determine the Type and Location of a Command

Before reading help for a command, confirm how the shell resolves it — builtin, alias, or external executable.

```bash
type ls
type cd
type cat
```

- If `cd` is a shell builtin, use `help cd` for its documentation instead of `man cd`.
- If `ls` is aliased, `type` shows the alias expansion before you read its options.

For an external command, confirm the full path on disk:

```bash
which cat
```

---

### 6. Search Man Pages by Topic with apropos

When you know what you want to do but not which command to use, search all man page descriptions by keyword.

```bash
apropos "list directory"
```

If `apropos` returns `nothing appropriate`, the man page database may need rebuilding:

```bash
sudo mandb
```

---

### 7. Read Info Documentation for GNU Commands

For GNU tools such as `ls`, `grep`, and `tar`, read extended documentation with `info`.

```bash
info ls
```

Navigate with `n` (next node), `p` (previous node), `u` (up one level), and `q` (quit).

> **Note:** If a topic has no dedicated info page, `info` falls back to the man page.

---

## Verification

Confirm the help tools are working by running each of the following and receiving output:

```bash
ls --help | head -5
man -f ls
type ls
whatis ls
```

Each command should return usable output without error. A `man -f` result identical to `whatis` confirms the man page database is current.

---

## Troubleshooting

| Problem | Cause | Solution |
|---|---|---|
| `whatis ls` returns `ls: nothing appropriate` | Man page database is out of date or not yet built | Run `sudo mandb` to rebuild, then retry |
| `command --help` exits immediately or shows an error | Command does not support `--help`; may be a shell builtin | Run `help commandname` for builtins, or `man commandname` |
| `man ls` displays `No manual entry for ls` | The `man-pages` package is not installed | Run `sudo dnf install man-pages man-db` |
| `apropos keyword` returns nothing | Database not indexed, or keyword too specific | Run `sudo mandb`, then try a broader keyword |
| `info command` shows a generic reader rather than the command's page | No standalone info page exists for that command | Fall back to `man commandname` or `commandname --help` |
